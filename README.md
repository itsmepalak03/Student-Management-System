# 🎓 Student Management System

A simple and user-friendly Student Management System developed using Java, JSP, Servlets, JDBC, and MySQL. This project allows users to manage student records efficiently through a web-based interface.

---

## 📌 About The Project

The Student Management System is a web application designed to perform basic student record management operations. It provides functionalities such as adding new students, viewing student details, updating student information, and deleting student records.

The project follows the MVC (Model-View-Controller) architecture and uses Java technologies for backend development.

---

## 🚀 Features

- User Login Authentication
- Add New Student Records
- View All Students
- Update Existing Student Details
- Delete Student Records
- Database Connectivity using JDBC
- Session Management
- Error Handling
- Simple and Responsive User Interface

## ⚙️ How It Works

1. User opens the application.
2. User logs in using valid credentials.
3. After successful login, the user can:
   - Add new students
   - View student records
   - Update student information
   - Delete student records
4. All data is stored and managed using a MySQL database.
5. JDBC is used to establish communication between Java and MySQL.
